# チェスクエスト

ブラウザで動くチェスゲームです。PWA 対応なので、ホーム画面に追加してアプリのように使えます（オフラインでも動作）。

## 機能

- **あそびかた（チュートリアル）**: ピピと一緒に、実際に駒を動かしながらルールを覚える全14レッスン（駒の動き・取り方・チェック・チェックメイト・キャスリング・プロモーション・アンパッサン・引き分け）
- **インストール方法の説明**: iPhone・iPad / Android / パソコン別の手順。タイトル画面の「インストール」（インストール済みなら非表示）・あそびかた・せっていから開ける
- **タイトル画面**（ファンタジーRPG風）: 「つづきから」「ストーリーモード」「フリー対戦」「せってい」を選べる。「フリー対戦」を選ぶと従来のCPU対戦・2人対戦メニューへ
- **ストーリーモード「影の塔」**: 10人の守り手と順番に対戦。勝つと次の話が解放される。各話の前後に会話シーンあり（プロローグ・エンディング付き）。CPUは話が進むごとに強くなる（10段階）
- **CPUと対戦**: 強さは「やさしい / ふつう / つよい」の3段階。先手・後手・ランダムを選べます
- **2人で対戦**: 1台の端末で交互に指します。手番の側が手前に来るよう盤が自動で回転します
- 合法手の表示、チェック表示、最終手のハイライト
- タップでもドラッグでも駒を動かせる。駒は滑るように移動
- 効果音（Web Audio で合成）と振動フィードバック。メニューでオン/オフ切替
- ストーリーの会話は文字に合わせて「しゃべり音」が鳴る（キャラごとに声の高さが違う）
- 8bit風のBGM（自作曲を Web Audio で演奏）。タイトル・ステージ選択・会話・対局・ボス戦でそれぞれ別の曲。メニューでオン/オフ
- 新しいバージョンを公開すると、画面下に「更新」ボタンが出て、押すとすぐ最新版に切り替わる
- キャスリング・アンパッサン・プロモーション（成る駒を選択）
- 終局判定: チェックメイト / ステイルメイト / 同一局面3回 / 50手ルール / 駒不足
- 待った、盤の反転、棋譜表示（SAN形式）、取った駒の表示
- 対局は自動保存され、「前回の続きから」で再開できます

### デバッグモード（ストーリー確認用）

タイトル画面のロゴ（ナイトの紋章と「チェスクエスト」）を素早く5回タップ（または URL に `?debug=1` を付ける）でオン／オフ。
オンの間はストーリーの全話が開放され、各話をタップすると「開始前の会話」「勝利後の会話」の再生、負け・王手のせりふの確認、「クリア扱いにする」ができます。プロローグ・エンディングの再生と進行リセットも可能です。

## 起動方法

Service Worker を使うため、HTTP サーバー経由で開いてください（`file://` では PWA として動作しません）。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

ホーム画面への追加（インストール）には HTTPS での公開が必要です。GitHub Pages などにそのまま置けば動きます（ビルド不要）。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 画面と操作 |
| `chess.js` | ルールエンジン（合法手生成・終局判定・棋譜） |
| `tutorial.js` | あそびかた（レッスンのデータと練習用の盤） |
| `scene.js` | ストーリーの会話シーン |
| `pwa.js` | 更新のお知らせ・インストール方法 |
| `pieces.js` | 駒のイラスト（SVG） |
| `story.js` | ストーリーの会話・キャラクターの顔イラスト（SVG） |
| `feedback.js` | 効果音と振動 |
| `ai.js` | CPU の思考ルーチン（Web Worker で実行） |
| `sw.js` | Service Worker（オフライン用キャッシュ） |
| `manifest.webmanifest` / `icons/` | PWA 設定とアイコン |

ファイルを更新して公開するときは、`sw.js` の `CACHE` のバージョンを上げてください。上げると、利用者の画面に「新しいバージョンがあります［更新］」が表示されます。

## CPU の強さ

| レベル | 内容 |
| --- | --- |
| やさしい | 1手読み＋大きめのランダム性（ときどき適当な手を指す） |
| ふつう | 3手読み＋駒の取り合いを最後まで読む静止探索 |
| つよい | 反復深化αβ探索（約2.5秒・最大8手読み） |
