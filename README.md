# シンプルチェス

ブラウザで動くチェスゲームです。PWA 対応なので、ホーム画面に追加してアプリのように使えます（オフラインでも動作）。

## 機能

- **CPUと対戦**: 強さは「やさしい / ふつう / つよい」の3段階。先手・後手・ランダムを選べます
- **2人で対戦**: 1台の端末で交互に指します。手番の側が手前に来るよう盤が自動で回転します
- 合法手の表示、チェック表示、最終手のハイライト
- タップでもドラッグでも駒を動かせる。駒は滑るように移動
- 効果音（Web Audio で合成）と振動フィードバック。メニューでオン/オフ切替
- キャスリング・アンパッサン・プロモーション（成る駒を選択）
- 終局判定: チェックメイト / ステイルメイト / 同一局面3回 / 50手ルール / 駒不足
- 待った、盤の反転、棋譜表示（SAN形式）、取った駒の表示
- 対局は自動保存され、「前回の続きから」で再開できます

## 起動方法

Service Worker を使うため、HTTP サーバー経由で開いてください（`file://` では PWA として動作しません）。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

ホーム画面への追加（インストール）には HTTPS での公開が必要です。GitHub Pages などにそのまま置けば動きます（ビルド不要）。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 画面と操作 |
| `chess.js` | ルールエンジン（合法手生成・終局判定・棋譜） |
| `feedback.js` | 効果音と振動 |
| `ai.js` | CPU の思考ルーチン（Web Worker で実行） |
| `sw.js` | Service Worker（オフライン用キャッシュ） |
| `manifest.webmanifest` / `icons/` | PWA 設定とアイコン |

ファイルを更新して公開するときは、`sw.js` の `CACHE` のバージョンを上げてください。

## CPU の強さ

| レベル | 内容 |
| --- | --- |
| やさしい | 1手読み＋大きめのランダム性（ときどき適当な手を指す） |
| ふつう | 3手読み＋駒の取り合いを最後まで読む静止探索 |
| つよい | 反復深化αβ探索（約2.5秒・最大8手読み） |
